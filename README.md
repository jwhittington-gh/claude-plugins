# claude-plugins

Claude Code plugins.

| Plugin | What it does |
|---|---|
| [spend-statusline](plugins/spend-statusline) | Status line with session/day/week/month spend, daily average, and a monthly budget projection |
| [live-plan](plugins/live-plan) | Live pane of the agent's plan steps and running shells with ETAs, plus a `/queue` for follow-up tasks |

## Install

```
/plugin install spend-statusline --marketplace jwhittington-gh/claude-plugins
/plugin install live-plan --marketplace jwhittington-gh/claude-plugins
```

Each plugin installs on its own; install either or both.

Then follow the plugin's README for setup.
